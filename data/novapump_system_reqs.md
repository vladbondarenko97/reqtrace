# Novapump NP-200 System Requirements (SYNTHETIC)

> Fictional device. All content is synthetic.

- **NP-SYS-001** — Insulin Delivery: The system shall deliver insulin accurately and on command in each supported delivery mode.
- **NP-SYS-002** — Dose Limits: The system shall prevent delivery of a single dose above the limit configured for the active user profile.
- **NP-SYS-003** — Unintended Use Protection: The system shall protect against unintended activation of bolus delivery.
- **NP-SYS-004** — Alarms: The system shall alert the user to conditions that interrupt or endanger therapy.
- **NP-SYS-005** — Event Records: The system shall keep a record of delivery events.
- **NP-SYS-006** — User Interface: The system shall provide a physical and on-screen interface for operating the pump.
- **NP-SYS-008** — User Profiles: The system shall support distinct user profiles with different delivery restrictions.
- **NP-SYS-009** — Power: The system shall report remaining battery and reservoir capacity to the user.
