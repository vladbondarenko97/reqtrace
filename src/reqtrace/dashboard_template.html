How to read this

  • Measured numbers come from llm_log.jsonl. The "list cost" is the per-call figure the Claude Code CLI reports itself.
  • Projected numbers use pricing.json (illustrative rates) and a straight-line scale-up. They ignore prompt caching, batch discounts and negotiated rates, and they assume the local model keeps its quality on a longer document, which the eval above only demonstrates at demo size.
  • Local tokens are free per token. The cost shown for them is electricity at the machine wattage in pricing.json. The real price of local is time: see the "local model time" cell above.
  • Local token counts use a different tokenizer from the hosted models, so token counts differ a little between columns.
